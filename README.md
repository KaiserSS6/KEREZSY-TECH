KerezsyTech

Archivos:
- index.html: página principal (carrusel, búsqueda).
- products.html: listado filtrable por categoría.
- products-data.js: catálogo de ejemplo.
- products.js: lógica para mostrar y agregar al carrito.
- cart.html: ver y editar carrito (localStorage).
- styles.css, script.js: estilos y scripts de la página principal.

Abrir:
- Doble clic en index.html o iniciar un servidor local:
  python -m http.server 8000
  Abrir http://localhost:8000
